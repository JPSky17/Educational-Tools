Numberlands is a K-5 math role playing adventure game where students travel through Six Kingdoms. Each kingdom covers a core grade-level skill: counting (K), addition and subtraction (1st), skip-counting (2nd), multiplication and division (3rd), fractions (4th), and mixed operations (5th). Kids answer short quiz questions, with visual models for counting and fractions, to earn stars and XP. Along the way, the student will level up a customizable hero and unlock gear including a helmet, a magical glowing sword, a baby dragon, a shield, and finally, a crown.
Progression is built around mastery. Each progressive kingdom unlocks the next once the student earns 2 stars. In between each kingdom the student has a chance to improve their math skills with a “Math Muncher” arcade mini-game for extra practice on the same skill. Difficulty adapts within each kingdom: three correct answers in a row raises the level, and two misses lowers it, so kids stay challenged without getting stuck. After clearing all six kingdoms, players face a Dragon Rider Showdown that mixes every skill followed by a typed-answer Skyfire Flight challenge, which upon completion triggers a final treasure victory scene.
It's a single-file HTML/CSS/JS app with no dependencies. Problems are generated on the fly, so every playthrough is different.
